# Clarity - Personal Expense Tracker

Clarity is a personal expense tracking app that helps users understand their finances better. It allows adding, editing, deleting, and viewing transactions, filtering by category or date, and provides a dashboard summary of income and expenses.

This repository currently contains the **backend API**, which is fully functional. The frontend (React + TypeScript) is under development and will be integrated soon.

---

## Features (Backend)

- User authentication (Sign Up / Login)
- CRUD operations for transactions
- Filtering transactions by category and date range
- Dashboard-ready endpoints (totals, summaries, category breakdowns)
- Clean MVC architecture with service layer
- Error handling and input validation

---

## Tech Stack

- **Backend:** Node.js, Express.js
- **Database:** MongoDB (Mongoose)
- **Authentication:** JWT
